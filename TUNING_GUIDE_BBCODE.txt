[size=6][b]EnhancedCombatAI — Tuning Guide[/b][/size]

This guide explains how to tune EnhancedCombatAI for your setup, whether you run an animation-driven combat overhaul ([b]MCO / BFCO / SCAR[/b]) or [b]vanilla / lightweight[/b] melee. It covers what each important setting does, how the pieces interact, and gives ready-to-use presets.

Everything here maps to [font=Courier New]Data/SKSE/Plugins/EnhancedCombatAI.ini[/font]. If you have [b]SKSE Menu Framework[/b] installed you can change all of it live in-game (Mod Control Panel → [b]Enhanced Combat AI → Config[/b]) and hit [b]Save to INI[/b] when you like the result — no restarts, no recompiles.

[line]

[size=5][b]1. The one setting most people need: reach[/b][/size]

NPCs decide "am I close enough to attack?" by comparing the distance to their target against their [b]effective attack range[/b]:

[code]effective range = WeaponReach × OffenseReachMultiplier + target body radius[/code]

[list]
[*][b]WeaponReach[/b] comes from [b]Precision[/b] if installed (accurate, per-weapon capsule length), otherwise a vanilla fallback (~130 units for a typical weapon).
[*][b]target body radius[/b] is added automatically so the check works against large enemies (trolls, giants) as well as humans.
[*][b]OffenseReachMultiplier[/b] (in [font=Courier New][DecisionMatrix][/font]) is [i]your[/i] knob. It's the single most important value for how aggressively NPCs commit to attacks.
[/list]

[quote][b]Install Precision.[/b] Without it, reach is a rough approximation and every reach-based decision degrades. It's the single biggest quality improvement for this mod.[/quote]

[b]How to tune it[/b]
[list]
[*]NPCs [b]hang back / circle without swinging[/b] → raise [font=Courier New]OffenseReachMultiplier[/font].
[*]NPCs [b]lunge / attack from clearly too far[/b] → lower it.
[/list]

Because animation-driven attacks (MCO/BFCO) physically travel the character forward during the swing, they connect from farther than vanilla's near-instant hits. So overhauls generally want a [b]higher[/b] multiplier than vanilla.

[list]
[*][b]Vanilla / lightweight melee:[/b] OffenseReachMultiplier = [b]1.0 – 1.1[/b]
[*][b]MCO / BFCO / SCAR (lunging attacks):[/b] OffenseReachMultiplier = [b]1.3 – 1.5[/b]
[/list]

[line]

[size=5][b]2. Integrations — match them to your load order[/b][/size]

Section [font=Courier New][ModIntegrations][/font]. These auto-detect, but set them explicitly so your intent is clear. [b]These apply at game load — restart after changing them.[/b]

[list]
[*][font=Courier New]EnableBFCOIntegration[/font] — turn on with BFCO / MCO (via BFCO) / any MCO-framework attacks
[*][font=Courier New]EnablePrecisionIntegration[/font] — turn on with Precision (strongly recommended for everyone)
[*][font=Courier New]EnableCPRIntegration[/font] — turn on with Combat Pathing Revolution (adds circling / fallback / advance)
[*][font=Courier New]EnableTKDodgeIntegration[/font] — turn on with TK Dodge RE (lets NPCs dodge)
[/list]

If you run [b]MCO without BFCO's NPC attack framework[/b], keep [font=Courier New]EnableBFCOIntegration = true[/font] anyway — the mod falls back gracefully and still drives normal/power attacks; it just won't fire BFCO-specific directional attacks.

[line]

[size=5][b]3. Offense: attacks, power attacks, sprint attacks[/b][/size]

Section [font=Courier New][DecisionMatrix][/font].

[list]
[*][b]EnableSprintAttack[/b] — the gap-closer. Feels great with MCO/BFCO (dedicated sprint-attack animations). On vanilla it uses the vanilla sprint attack, which is weaker/janky — some players prefer it off so NPCs just run in and swing.
[*][b]SprintAttackMinDistance / SprintAttackMaxDistance[/b] — the distance band where a sprint attack is considered. Default [font=Courier New]220–400[/font]. Widen the max for gap-closers from farther out.
[*][b]EnablePowerAttackStaminaCheck / EnableSprintAttackStaminaCheck[/b] — when [font=Courier New]true[/font], NPCs won't power/sprint attack on empty stamina. Keep [font=Courier New]true[/font] for fairness; set [font=Courier New]false[/font] for relentless pressure.
[*][b]Normal attacks are never stamina-gated[/b] — an NPC at 0 stamina can still swing.
[/list]

[line]

[size=5][b]4. Scoring weights — shape the AI's personality[/b][/size]

Section [font=Courier New][ScoringWeights][/font]. When several actions are valid, each gets a [b]priority[/b]; the highest wins. Base priorities decide the default lean; modifiers push priority up when an opening exists.

Base priorities ([font=Courier New]0.0–5.0[/font], higher = chosen more often):
[list]
[*][font=Courier New]AttackBase[/font] — normal/power attack in range
[*][font=Courier New]SprintAttackBase[/font] — gap-closer attack
[*][font=Courier New]AdvancingBase[/font] — run toward target
[*][font=Courier New]InterruptPowerAttackBase[/font] — bash to interrupt a power attack
[*][font=Courier New]EvasionDodgeBase[/font] — dodge / strafe spacing
[*][font=Courier New]BackoffBase[/font] — back off from caster/archer
[*][font=Courier New]FlankingBase[/font] — flank with allies
[/list]

Offense modifiers ([font=Courier New]0.0–3.0[/font], added when the situation applies): [font=Courier New]TargetStaggeredBonus[/font], [font=Courier New]TargetCastingBonus[/font], [font=Courier New]TargetRecoveryBonus[/font], [font=Courier New]TargetFleeingBonus[/font], [font=Courier New]TargetLowHealthFinisherBonus[/font], [font=Courier New]OpeningRiskPenalty[/font], [font=Courier New]FlankingAttackBonus[/font], [font=Courier New]AllyCoverBonus[/font].

[b]Want more aggression?[/b] Raise [font=Courier New]AttackBase[/font] / [font=Courier New]SprintAttackBase[/font], lower [font=Courier New]OpeningRiskPenalty[/font] and [font=Courier New]EvasionDodgeBase[/font].
[b]Want more tactical/defensive?[/b] Raise [font=Courier New]EvasionDodgeBase[/font], [font=Courier New]OpeningRiskPenalty[/font], [font=Courier New]BackoffBase[/font]; lower [font=Courier New]AttackBase[/font].

Tuning these live in the menu is the fastest way to find a feel — sliders update the AI instantly.

[line]

[size=5][b]5. Humanizer — how "human" they feel[/b][/size]

Section [font=Courier New][Humanizer][/font]. This is combat [i]feel[/i], independent of your combat overhaul.

[list]
[*][b]BaseReactionDelayMs[/b] — delay before reacting (at level 1, shrinks with NPC level). Lower = sharper/harder. [font=Courier New]150–200[/font] is a good band.
[*][b]MinMistakeChance[/b] — floor on mistake chance so even max-level NPCs occasionally slip. [font=Courier New]0.0[/font] = robotic-perfect elites; [font=Courier New]0.05[/font] = they stay human.
[*][b]Cooldowns[/b] ([font=Courier New]BashCooldownSeconds[/font], [font=Courier New]DodgeCooldownSeconds[/font]) — prevent spam. Lower bash cooldown = more counter-play.
[*][b]Mistake multipliers[/b] — per-action error scaling. Raise [font=Courier New]DodgeMistakeMultiplier[/font] if NPCs dodge too perfectly, etc.
[/list]

[line]

[size=5][b]6. Presets[/b][/size]

Copy the relevant block into the matching INI sections. Adjust to taste afterward.

[size=4][b]A) MCO / BFCO / SCAR (animation-driven, committed attacks)[/b][/size]

[code][DecisionMatrix]
OffenseReachMultiplier      = 1.4
EnableSprintAttack          = true
SprintAttackMinDistance     = 220.0
SprintAttackMaxDistance     = 450.0
EnablePowerAttackStaminaCheck  = true
EnableSprintAttackStaminaCheck = true

[Humanizer]
BaseReactionDelayMs = 180.0
MinMistakeChance    = 0.05
BashCooldownSeconds = 2.5

[ScoringWeights]
AttackBase       = 1.0
SprintAttackBase = 1.3
OpeningRiskPenalty = 0.4[/code]

Rationale: overhaul attacks lunge forward, so a wider reach ([font=Courier New]1.4[/font]) keeps NPCs committing instead of whiffing at the edge. Sprint attacks shine with BFCO gap-closer animations.

[size=4][b]B) Vanilla / lightweight melee[/b][/size]

[code][DecisionMatrix]
OffenseReachMultiplier      = 1.05
EnableSprintAttack          = false
EnablePowerAttackStaminaCheck  = true
EnableSprintAttackStaminaCheck = true

[Humanizer]
BaseReactionDelayMs = 180.0
MinMistakeChance    = 0.05
BashCooldownSeconds = 2.5

[ScoringWeights]
AttackBase       = 1.1
SprintAttackBase = 1.0
OpeningRiskPenalty = 0.4[/code]

Rationale: vanilla hits are near-instant and short-range, so a tight reach ([font=Courier New]1.05[/font]) avoids attacking from too far. Sprint attack often feels off in vanilla — leaving it off makes NPCs advance and swing normally.

[size=4][b]C) "Souls-like" harder duels (either combat base)[/b][/size]

[code][DecisionMatrix]
EnableEvasionDodge = true

[Humanizer]
BaseReactionDelayMs = 120.0
MinMistakeChance    = 0.0
BashCooldownSeconds = 2.0
DodgeCooldownSeconds = 1.5

[ScoringWeights]
EvasionDodgeBase   = 1.5
OpeningRiskPenalty = 0.5
BackoffBase        = 1.9[/code]

Rationale: fast reactions, no mistakes, more spacing/dodging and interrupts. Pair with a higher [font=Courier New]OffenseReachMultiplier[/font] from preset A/B for your combat base.

[size=5][b]7. Quick troubleshooting[/b][/size]

[list]
[*][b]NPC won't attack even point-blank:[/b] Install Precision; raise [font=Courier New]OffenseReachMultiplier[/font]. Check log [font=Courier New]Misc: WeaponReach=[/font] — should be ~100+, not ~1.3.
[*][b]NPCs attack from visibly too far:[/b] Lower [font=Courier New]OffenseReachMultiplier[/font].
[*][b]Too passive / circle forever:[/b] Raise [font=Courier New]AttackBase[/font] / [font=Courier New]SprintAttackBase[/font]; lower [font=Courier New]EvasionDodgeBase[/font], [font=Courier New]OpeningRiskPenalty[/font].
[*][b]Too aggressive / suicidal:[/b] Raise [font=Courier New]OpeningRiskPenalty[/font], [font=Courier New]EvasionDodgeBase[/font], [font=Courier New]BackoffBase[/font]; enable stamina checks.
[*][b]Feels robotic:[/b] Raise [font=Courier New]MinMistakeChance[/font] (e.g. [font=Courier New]0.05[/font]) and [font=Courier New]BaseReactionDelayMs[/font].
[*][b]Sprint attacks look janky (vanilla):[/b] [font=Courier New]EnableSprintAttack = false[/font].
[/list]

To diagnose reach/range issues, set [font=Courier New]EnableDebugLog = true[/font] and read the per-actor lines in [font=Courier New]Documents\My Games\Skyrim Special Edition\SKSE\EnhancedCombatAI.log[/font]: [font=Courier New]RangeCat[/font], [font=Courier New]InAtkRange[/font], [font=Courier New]WeaponReach[/font], and [font=Courier New]TargetBoundRadius[/font] tell you exactly what the AI thinks the geometry is.

[i]Tip: with SKSE Menu Framework, tune everything live, then Save to INI. It's far faster than editing the file and reloading.[/i]
